# Lucent HUD v1.1 — Visual Refinement

Дата: 2026-11-02. Ветка: `feat/game-ui`. PR не создавался.

## Результат

Выполнена точечная переработка оформления существующих HUD-модулей. Источники данных, inventory/weapon selection, ammo/ninja calculations, расчёты времени, finish/checkpoint states, цвета предупреждений и fade timings сохранены. Новых настроек и функций для игрока нет. ESC, scoreboard, networking, prediction, physics и chat на этом этапе не изменялись.

- Hotbar компактнее, ширина определяется фактическим числом слотов. Неподвижных пустых слотов нет. Иконки используют прежние игровые textures/quad containers, с более светлым отображением неактивного оружия. Активный слот имеет мягкую фиолетовую заливку и тонкий скруглённый контур вместо яркой нижней полосы.
- У таймера полностью удалена прямоугольная подложка. Основное и вторичное время образуют компактный текстовый блок с небольшой тенью и существенно более слабой обводкой. Его фактические bounds продолжают использоваться для размещения соседних индикаторов.
- Recording стал тоньше: маленькая красная точка, приглушённые метки REC/AUTO/RACE/REPLAY и более крупное светлое время manual/auto. Показ/скрытие и порядок recorders сохранены. Раздельные текстовые кэши используются только для оформления меток и длительности.
- Coordinates сохраняет горизонтальную строку и прежние данные. Сокращены padding и высота, унифицированы фон, радиус и типографика. Нейтральная строка скорости использует вторичный цвет; её сигнальные цвета сохранены.
- Общие поверхности больше не имеют смещённой тени и декоративной акцентной линии. Новых аллокаций для слотов/контуров в горячем пути не добавлено: контур строится в фиксированных stack arrays; тексты продолжают использовать существующий кэш и soft recreation.

## Изменённые размеры и отступы

Числа ниже приведены в **HUD units** при `lucent_hud_scale 100`: HUD использует высоту 300, а стандартная UI-система меню — 600. Поэтому 1 HUD unit соответствует 2 UI units. Физические пиксели зависят от разрешения и выбранного масштаба HUD.

| Элемент | v1 | v1.1 |
| --- | --- | --- |
| Размер слота | 26 × 21 | **22 × 20**, то есть **44 × 40 UI units** |
| Зазор слотов | 4 | **2.5**, то есть **5 UI units** |
| Внешний padding hotbar | 5 по X, 3 по Y | **2 по обеим осям** |
| Высота hotbar | 27 | **24** |
| Ширина hotbar для N слотов | `26N + 4(N−1) + 10` | **`22N + 2.5(N−1) + 4`** |
| Ширина для 1 / 6 слотов | 36 / 186 | **26 / 148.5** |
| Масштаб иконки относительно прежнего HUD quad | 1.00 | **0.78**, чтобы иконка помещалась в компактный слот |
| Центр иконки по Y внутри слота | 8 | **7** |
| Контур активного слота | Нижняя полоса толщиной 1 | **Скруглённый контур 0.35**, radius 2 |
| Основной размер шрифта таймера | 15 | **14** |
| Вторичный размер шрифта | 6 | **6**, сохранён |
| Y основного / вторичного времени | 3 / 24 от верха bounds | **0 / 19** |
| Высота bounds timer: основное / оба / только вторичное | 24 / 33 / 15 | **18 / 26 / 10**, без рисования панели |
| Минимальная ширина timer bounds | 68 | **Убрана**, bounds соответствуют тексту с запасом 4 |
| Recording: высота / диаметр точки | 15 / 3 | **12 / 2** |
| Recording: шрифт метки / времени | 6 / 6 | **5 / 6** |
| Recording: label-to-time / item gap | Одинаковая текстовая строка с пробелами | **2.5 / 5** |
| Recording: суммарный запас по X вокруг текста | 19 | **14**, включая точку и её отступ |
| Coordinates: padding X / Y | 5 / 4 | **4 / 3** |
| Coordinates: высота одной / двух строк | 15 / 25 | **13 / 22** |
| Coordinates: Y второй строки | 15 | **13** |
| Радиус общих поверхностей | 3 | **2** |

Внешний отступ от экрана 6, clearance между блоками 4 и диапазон существующего HUD scaling 50–150% сохранены. Резерв под существующий score HUD и разделение coordinates/hotbar сохранены.

## Изменённые цвета и прозрачности

RGB приведены в диапазоне 0–1. Все alpha по-прежнему умножаются на существующий `lucent_hud_opacity`.

| Параметр | v1 | v1.1 |
| --- | --- | --- |
| Основной текст | `(0.88, 0.87, 0.92)` | **`(0.96, 0.96, 0.99)`**, близкий к белому |
| Вторичный текст / recording labels | Общий цвет основного текста | **`(0.74, 0.72, 0.80)`** |
| Акцент | `(1.00, 0.82, 0.91)` | **`(0.70, 0.58, 0.92)`**, мягкий фиолетовый |
| Поверхность RGB | `(0.025, 0.021, 0.035)` | **`(0.045, 0.035, 0.065)`** |
| Alpha поверхности: общий / hotbar / recording | 0.78 / 0.78 / 0.78 | **0.60 / 0.58 / 0.34** |
| Смещённая тень поверхности | Alpha 0.18, offset Y 1 | **Удалена** |
| Верхняя декоративная линия | Alpha 0.15 | **Удалена** |
| Alpha неактивной иконки | 0.55 | **0.90**; активная остаётся 1.0 |
| Alpha заливки / контура активного слота | Заливка 0.16, нижняя полоса 1.0 | **Заливка 0.16, тонкий контур 0.55** |
| Alpha текстовой обводки | 0.70 | **0.18 для timer, 0.30 для остальных новых блоков** |
| Тень timer text | Отдельной тени не было | **Чёрная, alpha 0.28, offset (0.25, 0.4)** |

Красная точка, цвета последней минуты/мигания, положительной/отрицательной checkpoint difference и изменения скорости сохранены. Читаемость на ярких картах является целью этих изменений, но её фактическая визуальная оценка не выполнялась.
