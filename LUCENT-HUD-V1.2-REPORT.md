# Lucent HUD v1.2 — Final Polish

Дата: 2026-11-02. Ветка: `feat/game-ui`. PR не создавался.

## Что изменено

Использованы существующие HUD render methods, text cache, layout и surface helpers. Новых систем, конфигов или HUD Editor нет. ESC, scoreboard, chat, physics, prediction и networking на этом этапе не изменялись. Сигнальные RGB-цвета игровых индикаторов, условия показа и расчёты игровых данных сохранены.

### Hotbar

- Масштаб weapon sprite относительно существующего quad container: **0.78 → 0.92**, увеличение **17.95%** по обеим осям.
- Поворот **`pi * 7 / 4`** сохранён, сразу после отрисовки иконки выполняется reset в 0. Слоты и контуры не поворачиваются.
- Центр X остаётся серединой слота. Центр Y изменён с `slot.y + 7` на **`slot.y + slot.h / 2`**, то есть `slot.y + 10`. Это устраняет недостаточный верхний запас для увеличенного наклонённого спрайта.
- Размер слота **22 × 20 HUD units**, gap **2.5**, внешний padding **2**, высота hotbar **24**, формула ширины и позиция всей панели сохранены. Контейнер не увеличен.
- Texture selection, custom game skin path, alpha и ammo/ninja logic сохранены.

Геометрия сверена с `datasrc/content.py` и формулой нормализации существующего `GetSpriteScale`. Полный axis-aligned размер повёрнутого quad при масштабе HUD 100%:

| Оружие | Размер по X и Y, HUD units |
| --- | --- |
| Hammer | 21.858 |
| Gun | 13.965 |
| Shotgun | 18.933 |
| Grenade | 19.301 |
| Laser | 19.647 |
| Ninja | 18.933 |

Все шесть укладываются по X в слот шириной 22 и по Y в существующую панель высотой 24. Полный quad hammer по высоте использует часть внешнего padding, а не увеличенный контейнер или обрезку. Проверена геометрия, а не фактический кадр с каждым skin.

### Назначение таймеров

Исследованы `CHud::RenderGameTimer`, `RenderDDRaceEffects`, существующий `OnMessage` и `RenderLucentTimer`:

- **Основное время** вычисляется из текущего server game tick: остаток time limit, race time через отрицательный warmup offset либо elapsed round time. Это текущие игровые часы с точностью отображения до секунды.
- **Дополнительная строка** — независимое событие DDRace: checkpoint difference либо finish time и разница времени. Время/разница приходят существующими сообщениями; строка живёт шесть секунд и затухает после четырёх. Это не второй дублирующий running timer.
- Существующая возможность показать дополнительную строку при отключённом основном таймере сохранена. Finish/CP conditions, настройки, форматы, сигнальные цвета и длительности не менялись.
- Отдельные локальные часы `RenderLocalTime` показывают системное время суток и не являются checkpoint/race timer. Их оформление и код этого этапа не менялись.

Изменено только оформление timer block:

- Основной / вторичный шрифт остаётся **14 / 6 HUD units**.
- Внутренний отступ сверху и снизу унифицирован до **2 units**; промежуток между строками — **3 units** вместо 5.
- Y основного текста относительно bounds: **0 → 2**. Y дополнительной строки при наличии основной остаётся **19**; при показе только дополнительной строки — **1 → 2**.
- Bounds для основной строки / обеих / только дополнительной: **18 / 26 / 10 → 18 / 27 / 10**. Это резерв для размещения, массивная панель не рисуется.
- Alpha тонкой чёрной обводки timer text: **0.18 → 0.30**, теперь совпадает с остальным текстом HUD. Alpha небольшой смещённой тени: **0.28 → 0.36**; offset остаётся **(0.25, 0.4)**, масштабируется вместе с HUD.
- Существующее размещение recording под таймером при пересечении продолжает учитывать актуальные bounds. Существующие pause/warmup/connection notifications также используют эти bounds. Их собственные anchors и код не менялись.

Обводка и небольшая тень предназначены для контраста на светлом фоне; светлый основной текст — для тёмного. Реальная читаемость на картах вручную не оценивалась.

### Общая палитра, recording и coordinates

Все поверхности hotbar, recording и coordinates теперь используют одинаковую базовую alpha **0.58**: раньше было **0.58 / 0.34 / 0.60** соответственно. Это устраняет особенно слабый контраст recording на светлом фоне. Значение умножается на существующий `lucent_hud_opacity`, новых настроек нет.

| Визуальный параметр | Итог |
| --- | --- |
| Фон | RGB **(0.045, 0.035, 0.065)**, прежний нейтрально-фиолетовый |
| Основной текст | RGB **(0.96, 0.96, 0.99)**, сохранён |
| Вторичный текст | RGB **(0.74, 0.72, 0.80) → (0.80, 0.78, 0.85)** |
| Акцент | RGB **(0.70, 0.58, 0.92)**, сохранён |
| Radius поверхностей и active-slot fill | Общая константа **2 HUD units**, геометрически без изменения |
| Основной размер текста / caption | Общие константы **6 / 5 HUD units**, без изменения размеров |
| Вертикальный text padding плашек | Общая константа **3 HUD units**, без изменения позиций |
| Recording labels | Дополнительные 0.5 units по Y сохранены для выравнивания шрифта 5 с временем размером 6 |

Высота и расположение recording/coordinates, их горизонтальные отступы, статусная точка и форматы данных сохранены. Новых тяжёлых теней или рамок поверхностей нет. Красная точка, last-minute/blink, положительная/отрицательная checkpoint difference и сигнальные цвета скорости не менялись.
